# Complete counter-qualified return filters

Wave Goodbye's frozen failure is an explicit blanket rejection in the return-all
shape reader. The ordinary object-filter reader and return instruction already
support typed counter exclusions. This increment admits only a complete
`WithoutCounter` decoration recognized by that shared grammar; it keeps the
whole original filter and leaves unknown qualifiers rejected. It does not strip
counter words or change the runtime return primitive.

The full frozen body and Oracle identity are retained in
`fixtures/counter_qualified_return.json.fixture`. Independent direct/artifact
scenarios actually pay and resolve the spell, distinguish +1/+1 from other
counters, retain current creature and owner-hand scope, and verify Shroud does
not create targeting. Other cases alter counters and add a creature after
announcement, resolve an empty board, and reject unknown qualification tails.
All scenarios are unrun. No builds, compilation, compiler probes, tests,
formatters or engine/corpus execution occurred. This is a source proposal only,
pending independent review; no measured recovery or exhaustive runtime claim.

Grip of Desolation is deliberately outside this proposal. Its separate
same-instruction, independently targeted exile set needs a proper completed
zone-move owner; admitting it as serial coordinated effects would not prove
simultaneous semantics.
