protocol from 19 to 20. Public audit digest version 3 retains its shape. The
artifact schema shape hash remains unchanged because the gate records a
semantic definition migration, not a claim that old payloads are equivalent.

opens the execution gate. Relabeling an old version or refreshing a checksum
does not migrate it. Old source-only cache hashes cannot establish that compiled
definitions are current. The direct materializer now performs the same version,
