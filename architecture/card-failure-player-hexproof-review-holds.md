# Retained-controller player targeting holds

A bounded source review found that player hexproof consults a permanent source's
current controller after an ability has entered the stack. If an opponent
steals that source while its ability remains controlled by the original player,
the old player-target restriction can allow an illegal target. Source-based
protection must still use the source's real characteristics; globally replacing
its controller would conflate two rules.

Five exact prior source proposals reach this owner: Aether Revolt, Ancient
Cellarspawn, Heretic's Punishment, Runebound Wolf and Stonehorn Dignitary. This is
a source-confirmed subset, not a claim that all affected cards were inventoried.
They are held pending the shared correction and independent review. The mixed
target bodies All Will Be One and Nicol Bolas, God-Pharaoh were never admitted.

Together with the five separate draw-quantity holds, the current conservative
source ledger has 1,217 unique proposals across 1,222 entries. Published PR863
remains the historical 1,227/1,232 source snapshot. No measured compile result
changed, and no execution was performed. A correction to this owner restores
its exact rule path; it is not a fresh whole-body or full-corpus validation.
