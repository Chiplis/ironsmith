## Shared semantic boundary

- Filtered transforms retain separate subject and destination characteristics.
  Both match the completed permanent; “non-Human creature” requires both type
  inclusion and subtype exclusion. Self + named-face triggers keep their existing
  source-face reader. The new serialized trigger variants are appended.
- Transform, mutation and face-up producers freeze checked post-change snapshots.
  Renown uses its existing keyword event and filtered-object matcher, now with
  the permanent's completed characteristics rather than the effect controller.
- Face-up keeps acting player and affected permanent's controller distinct.
  Effects supply their controller as the actor; paid special actions supply the
  player taking that action. A changed controller cannot rewrite this evidence.
- Equipped/enchanted lifecycle subjects bind the event object's recorded
  attachment list. Detachment or reattachment before dispatch does not change
  the historical recipient. Empty captured tags prevent live attachment fallback.
- These transitions preserve ObjectId. A trigger's object reference cannot follow
  a later blink, including native execution contexts without a resolution floor.
  Explicit moves made by the resolving program retain their normal follow rules.

## Producer and recovery ownership

Effect and special-action producers freeze their participants after all
as-change programs. A single multi-object face-up instruction captures one
completed characteristic frame after every selected permanent changes.
Day/night retains its existing pending as-transforms list until those programs
finish; it publishes all completed notifications together before the SBA owner
matches them. Pending/error completion rolls back its native savepoint. The
shared wire-program guard rejects that nonempty pending list in both the
main turn and Grand Melee lanes (dependency `e6e978f54`, quantity-worker follow-up).

Mutation now publishes its notification through the pending-event owner when
public stack resolution has no explicit external trigger queue. Previously that
route recorded history but dropped the trigger notification. The explicit queue
path retains its existing behavior.

Compiled instruction boundaries already capture ordinary and delayed observers
before a later instruction changes them. Special-action and day/night completion
reach the existing priority/SBA drain before later actions. Snapshots/events are
cloned by native savepoints; unrepresented executable/history continuations are
covered by the shared fail-closed wire boundary. No new lossy snapshot transport
or event reconstruction is introduced here.
