# Static reader ambiguity roots (UNVALIDATED)

This bounded packet addresses four exact frozen failures: Bedlam, Orb of Dreams,
Noble's Purse, and Sphere of the Suns. Other static-registry ambiguity cards
remain outside this proposal.

The complete tapped-plus-counters grammar owns both entry effects, including
the optional conjunction in “tapped and with.” The counters-only reader now
declines that complete shape rather than producing a competing result missing
tapped. No ambiguity diagnostic or registry priority is suppressed.

The unfiltered global entry reader and its general filtered counterpart use the
same canonical AllPermanentsEnterTapped payload. Bedlam's complete global
prohibition uses the existing source-owned RuleRestriction from the generic
restriction reader. It is not a removable ability granted to each creature.
Both competing complete readers therefore produce equivalent typed results.

Authored direct and artifact-round-trip scenarios cover all four full bodies:
global restriction source lifetime/phasing and recipient ability loss; both
players and permanent types for Orb, including its own untapped entry; real
tapped/counter entries; three actual counter-paid activations; Treasure's full
mana ability; exhaustion and unrelated counters. Local grammar scenarios cover
both counter conjunction spellings and filtered versus unfiltered entry rules.

Orb's own entry is the explicit example in Comprehensive Rules 614.12:
https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.pdf
This is the campaign's pinned 2026-09-25 rules baseline.

All builds, compiler probes and tests remain deferred. Source inspection and
git diff checks do not establish measured compile or runtime recovery.
