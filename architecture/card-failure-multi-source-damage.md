## Captured-incarnation source permission prerequisite

`DamageSourceSetBinding` distinguishes ordinary live source members from an
explicit captured battlefield-incarnation set. The latter only accepts tagged
receipts; a live member uses its current calculated characteristics, while a
departed or phased member requires that exact incarnation's actual last-known
receipt. It never follows the stable card id into a returned object, and missing
history errors rather than substituting an older selection-time power.

A source quantity on a phased-out object reads its exact last-known receipt or
its retained exact source snapshot, rather than falling back to the physical
card's printed base power. Authored native cases capture at power 2, pump to 7,
change control, then keep it live / exile-return / phase it out. The captured
source deals 7 and credits the proper controller; default live-member mode stays
strict. Clearing the historical receipt leaves an explicit unresolved value.
This is the permission consumed by Alpha Brawl's second phase.

## Alpha Brawl complete two-phase composition

A bounded reciprocal-power relationship reader first declares and captures the
single targeted creature, then captures that creature's controller's other
creatures as exact battlefield identities. Phase one deals the original
creature's power to that fixed set as one occurrence. Phase two takes each
captured creature's current or actual last-known power and damages the exact
original permanent in a different simultaneous occurrence. Newly returned
incarnations are neither extra sources nor a replacement recipient.

A structural renderer proves the complete four-operation identity/scope/power
contract before rendering the reciprocal sentence; wrong controller, value or
source-binding mode is not compacted. No raw Oracle string is used as output.
Direct/artifact public-cast scenarios cover normal scope, no other creatures,
first-phase additions that pump/exile/return a captured secondary source, and
first-phase additions that blink the primary recipient. They pin one declared
target, distinct phase identities, one first-phase lifelink gain, actual departure
power, and no new-incarnation follow. All remain authored and unrun.

artifact, either remaining present or departing afterward. Source P/T reads use
