## Historical and current compatibility

Missing token-role metadata remains `None`/unknown and is omitted in the wire
schema. It is not reconstructed from names, rendered text or ability inventories.
Incomplete ability roles keep word edits held while independently proven name
policy can still control token creation.

The old native trigger fallback hashes effect Debug. A derived Debug with the
new absent field would change those historical inputs. The integration therefore
uses an exhaustive manual Debug implementation that preserves the old field
order and bytes when `text_roles` is absent. Present roles are included. This
does not rehash, stamp or normalize a live native identity; ordinary unstamped
native definitions with omitted roles retain their prior inputs.

The same unpublished artifact8 gate receives an explicit schema fingerprint
refresh under the documented source/hash procedure in
`card-failure-numeric-counter-compatibility.md`. Public digest4 and signed
audit21 do not change. Old format7 and pre-token staged schema envelopes remain
inadmissible even with fresh checksums. Original frozen inputs must eventually
be recompiled; neither relabeling nor inventing missing provenance is migration.
The pre-existing missing `fixtures/v5.json` artifact golden still blocks its
deferred golden scenario. No golden, cache, catalog or signed transcript changed.
