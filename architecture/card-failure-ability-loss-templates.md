# Ability-loss object templates (source proposal, UNVALIDATED)

Four full frozen baseline candidates are Gift of Tusks, Polymorphist's Jest, Snakeform and Turn to Frog. Turn // Burn remains a partial face-family fixture until split/Fuse announcement and both-face gameplay gates are authored; Mercurial Transformation's choice, Honest Work's static named/granted template and Azure Beastbinder's conditional follow-up remain separate partials.

The new named grammar accepts one complete targeted or duration-bounded `loses all abilities and becomes` template. It reuses the complete object-template descriptor and existing duration grammar, then carries ability loss on the same typed characteristic instruction. Lowering already registers type/color/base-P/T/loss modifications as one selected-object group. Empty authored card types stay empty, preserving Artifact on a creature that becomes a Frog; creature subtypes change independently. No new native effect or card-name dispatch is added.

The old blanket unsupported diagnostics defer only for this complete supported shape. Unknown properties, alternate template choices and extra tails remain strict failures. Both sentence and nested clause registries own the atomic instruction before generic gain/loss chains can separate its subject.

Authored, unrun scenarios exercise actual spell targets/costs, one player target for the global creature set, resolving-set capture and later entrants, controller changes, cleanup, printed abilities, existing counters, retained Snow/Artifact types, replacement creature subtypes, Snakeform's draw and no draw on an illegal sole target. Exact tools payloads and direct/JSON materialization use the same fixtures. The former rejection regression now asserts complete characteristic output and still rejects unknown trailing rules.

No builds, tests or engine/compiler probes were executed. Local source formatting/parser inspection only. Full corpus and supported-card validation remain deferred.
