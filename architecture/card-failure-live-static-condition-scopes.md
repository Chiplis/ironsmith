# Live static condition scopes (UNVALIDATED)

This source proposal closes four exact frozen bodies: Goblin Caves, Goblin Shrine,
Orochi Merge-Keeper and Viridian Betrayers. It does not assert measured compile
recovery. No compiler, build, test or engine probe has run.

The shared descriptor grammar retains complete compound filters such as a basic
Mountain, binding their subject to the current host of the source Aura/Equipment.
This is not a choice tag and does not bind to an anthem recipient. Existing simple
single-property descriptors retain their established representation. Descriptor
parsing and status suffixes consume their whole clause.

Modified source status uses the native source filter: counters, any Equipment,
or an Aura controlled by the creature's controller. Poisoned-player status uses
an existential count over the requested player set, excluding teammates from an
opponent set and ignoring departed players. Both are reevaluated from current
state through the existing continuous-condition owner.

Authored runtime scenarios cover strict direct/artifact bodies, paid Aura casting,
basic versus nonbasic/wrong-type hosts, foreign Goblin recipients, phasing and
reattachment, Shrine's leave-trigger damage, paid conditional mana activation,
controller-sensitive modification, team poison scope and actual infect damage.
Grammar regressions retain all compound descriptors and reject trailing unknown
conditions. The tools gate uses the exact frozen metadata and full Oracle bodies.

Essence Leak's compound color condition has source groundwork but its granted
upkeep payment program is not claimed complete. Top-library conditions for Mul
Daya Channelers, Vampire Nocturnus and Crown of Convergence, Isleback Spawn's
existential library size and Kianne's parity are explicit further work, not coverage.
