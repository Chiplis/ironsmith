## Typed boundaries

- Hedron Matrix's authored `its mana value` binds to the equipped creature, using
  `ManaValueOf(Iterated)` in the continuous layer. The binder requires an explicit
  attached subject and the actual possessive-it surface. It does not rebind a
  separate `that artifact` reference or an unresolved generic pronoun.
- Hancock's count is `CountersOn(Source, None)`: all counters on the ability source,
  not the number of counter kinds and not counters on each recipient. Existing
  matching-type OR, other/source exclusion and current controller scope remain.
- Glamdring uses the existing PowerOf value over a typed host filter requiring this
  exact source to be attached. Cost evaluation has no resolution tag table, so an
  unbound `equipped` tag would not suffice. A generic equipped-state fallback would
  also incorrectly borrow another Equipment's host while this source is unattached.
  The exact-source attachment relationship avoids both mistakes.

A separate positive capability guard admits only affected-object mana value and
source all-counter references (and their bounded existing arithmetic compositions)
to dynamic anthem layer evaluation. Other legacy Dynamic paths remain excluded.
Target wrappers, arbitrary tags, source-power recursion and event-local values do
not become admissible statics. No new serialized model variant is introduced.

The layer object-number adapter now reads mana value from its already-calculated
characteristic view. Copy and face-down layers can change mana cost without changing
the printed object fields. It reuses the existing calculated-mana-value helper,
including linked-face rules; actual mana spent still reads payment metadata.
The execution-mode interpreter's other legacy mana-value routes are not broadened.
