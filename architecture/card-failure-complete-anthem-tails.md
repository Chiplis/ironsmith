# Complete static anthem tails

UNVALIDATED source proposal; no build, compiler probe, corpus replay or test execution.

Sixteen proposed complete identities and one explicit partial are preserved in
`fixtures/complete_anthem_tails.json.fixture`. The common fault was that a valid
P/T modifier was followed by an independently meaningful predicate that the
plain anthem reader could not own. No trailing text is discarded.

## One complete shared-subject program

The existing continuing-segment reader now owns complete attack/blocker
restrictions, toughness-based combat damage, block requirements and continuous
goad designations alongside keyword and quoted ability grants. Blocking tails
reuse the existing fully typed blocking-cant facts and static factory. Shared
subjects, attachment references, controller sets and leading live conditions
remain attached to every generated effect.

A valid final type/color-addition tail alone no longer excludes this complete
reader. The competing specialized production must prove the entire line first.
Mixed quoted grants and explicit subtype additions use the existing conditional
addition lowerer, including receiving-object scopes for nested commander buffs
and triggered draw/discard programs. `all creature types` and `every creature
type` share the same typed family. Unknown tails or incomplete keyword bundles
fail closed instead of being silently filtered out.

The grouped quantity `for every N <objects>` is a positive checked divisor over
a typed live count, divided before each stat multiplier is applied. Zero or
unrepresentable divisors are rejected. It is not a rounded or frozen count.

## Goad is not an ability on the recipient

The complete compound and simple anthem/goad routes use native `GoadMatching`,
not an ability granted to the creature. The exact supplying attachment is a
required filter relation; an unattached Aura cannot fall back to any enchanted
creature. Losing the recipient's abilities leaves the designation active, while
source control, phase-out, detachment or departure change it correctly. The
[official Commander Masters release notes](https://magic.wizards.com/en/news/feature/commander-masters-release-notes)
state that goad survives ability loss and identify the goading controller.
The redundant runtime attachment proof is omitted only in presentation.
