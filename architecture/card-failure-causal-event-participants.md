## Shared typed boundary

Active clauses naming a spell or ability's controller use captured EventCause.
Countering controller is independent of the countered spell's controller;
destroying controller is independent of the destroyed permanent's controller.
A new appended Condition variant qualifies the existing event matcher at event
time. The cause's controller has its own reference tag for a body such as
“target permanent that opponent controls.” Runtime matching never reads Oracle.
Cost, state-based, unknown, and otherwise non-effect causes cannot satisfy the
spell/ability-effect qualification. Opponent matching respects teams.

Grouped caused discard retains both its cause qualification and quantifier
through lowering/serialization. Older JSON defaults to the original singular
semantics. A batch fires only for its first qualifying observation.

Successful destruction remains destruction when its graveyard destination is
replaced by exile. Regeneration, indestructibility, and other prevented attempts
do not publish successful destruction notifications. Completed destruction now
carries the full pinned pre-operation observer frame, so Justice destroyed in
the same instruction sees each qualifying permanent, while an observer departing
in an earlier instruction does not. Countered-spell receipts likewise declare
their complete old observer set; a later arrival cannot observe the old counter.
