# MPlantin

`MPlantin.ttf` is the user-supplied MPlantin Regular font from `~/Downloads/Mplantin.ttf`.

The bundled copy repairs the TrueType table directory search fields and non-Macintosh cmap language IDs, then recalculates table/font checksums so browsers accept it. Glyph outlines and spacing are unchanged. The original file in Downloads is untouched.

The inspector uses this font for both rendering and canvas text measurement. Bold and italic styles are synthesized from the supplied regular face.
